# Security Policy

Este repositório é tratado como referência técnica externa.

- Não adicionar credenciais ou dados pessoais.
- Não usar este espelho como fonte de segredos ou configurações de produção.
- Vulnerabilidades upstream devem ser tratadas segundo o processo do projecto de origem.
- Alterações MILK específicas devem permanecer claramente separadas do conteúdo upstream.
